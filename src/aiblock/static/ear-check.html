EAR CHECK
How this demo works
A quick guide to the Ear Check game and the AIBlock detection backend.
Demo guide
Overview

What you’re using

Ear Check is a small, self‑contained demo built on top of the AIBlock audio detection backend. It lets you practice spotting the difference between human recordings and AI‑generated music.

Game flow

How the round works

  • Listen: tap the big button to hear a short clip. You can pause and replay.
  • Guess: once you’ve listened for a few seconds, choose Human or AI.
  • Reveal: see whether you were right, how confident the model is, and one concrete cue to listen for.
  • Next clip: tap Next clip to move on and build a streak.

The clips are pre‑curated so the experience is fast and repeatable. Ear Check does not accept uploads in this demo.

Interpretation

How to read the verdict

  • Label – whether the clip is treated as human or AI in this game.
  • Model confidence – how far the backend’s score is from a 50/50 decision.
  • Listening cue – a specific artefact to replay (timing drift, vocal consistency, noise floor, etc.).

Confidence is a model output, not ground truth. It is useful for ranking and teaching, not as legal evidence.

Detection logic

What happens behind the button

Pipeline
  • Input: each clip has a public audio source (Deezer preview or AI‑native track) defined in a manifest.
  • Adapt: AIBlock fetches the audio and normalizes it (mono, fixed sample rate, chunked over time).
  • Detect: multiple detectors run on each chunk – for example spectral artefacts and prosodic cues.
  • Aggregate: per‑detector scores are combined into an overall ai_score and confidence using a confidence‑weighted mean.

Ear Check uses those precomputed scores to drive the verdict line and the difficulty of each clip. The UI never calls the heavy models in real time – that work has already been done by the backend.

What this demo is / isn’t

Scope and limitations

  • This is a teaching and exploration tool, not a certification service.
  • Short, compressed, or heavily processed audio can be hard for both humans and models.
  • Model behaviour and thresholds may evolve as the underlying research improves.

For API‑level integration, the same detection pipeline is exposed via AIBlock’s /v1/detect endpoints.
